# Changelog

## 0.1.0 - 2026-10-16

- 新增自带引擎的 macOS `Saber Theme.app`，支持 Intel 与 Apple Silicon；首次安装、更新和启动不再需要手工输入命令，关闭 Codex 前仍需确认。
- 新增 Windows 安装器、桌面／开始菜单启动、验证、诊断和暂停入口。共享同一套主题资源与 CDP 引擎，不修改官方应用；Windows Store 实际启动及界面效果仍待真机验收。
- 优化轮播：压缩 Blob 资源与常驻脚本分段传输；窗口隐藏时暂停；过渡结束释放隐藏图片引用；预加载支持取消、超时和失败回退。
- 加固重复注入的导航回调、定时器、观察器、图片资源及 CDP 异常连接清理，新增只读性能采样。
- 新增 2,000 次模拟轮播、200 次重复注入、真实 Chromium 图片轮播、启动器及 Windows 模拟检查，并配置 macOS／Windows CI。
- 同一隔离夹具中，120 次轮播后的 JavaScript 堆从单段传输约 22.4 MiB 降至分段传输约 1.05 MiB。该结果不代表整个 Codex、图片解码或 GPU 总内存，真实会话的长期卡顿仍需另行诊断。
- 统一以 `VERSION` 维护运行时、macOS 应用信息和带版本号的发布包，新增元数据一致性检查。

已知限制：macOS 发布包采用本地签名，未做 Apple 公证；完整页面刷新或新窗口需要再次点击启动器；默认安装和注入不额外常驻 Node 进程。

## 0.0.1 - 2026-07-20

首个 Codex Saber Theme 版本：

- 提供 `Saber Ice Atelier` 主题及首页、侧边栏、环境卡片、文件面板和代码审查面板装饰。
- 支持 Saber 动画叠层、减少动态效果设置和浅色界面适配。
- 默认安装并启用 `preset-saber-ice-atelier`。
- 安装目录为 `~/.codex/codex-saber-theme`。
- 提供测试、安装、验证、更新和恢复脚本。
